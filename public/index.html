Track Your Render & Cloudflare Deployments

Connect your Render and Cloudflare accounts to see live build statuses right after every Git push.

🟠 Render Accounts (Any number of accounts)

Get your API key at: Render Dashboard → Account Settings → API Keys.

# Option A: Numbered variables (Easiest in Cloudflare Pages) RENDER_API_KEY_1=rnd_yourKey1 RENDER_LABEL_1=Render - Personal RENDER_API_KEY_2=rnd_yourKey2 RENDER_LABEL_2=Render - Client Project # Option B: Comma-separated keys RENDER_API_KEYS=rnd_key1,rnd_key2

Services are auto-discovered automatically. No service IDs needed!

🔵 Cloudflare Accounts (Any number of accounts)

Get Account ID from sidebar and API Token at: My Profile → API Tokens → Edit Cloudflare Workers.

# Option A: Numbered variables (Easiest in Cloudflare Pages) CF_ACCOUNT_ID_1=your_cf_account_id_1 CF_API_TOKEN_1=your_cf_api_token_1 CF_LABEL_1=Cloudflare - Main CF_ACCOUNT_ID_2=your_cf_account_id_2 CF_API_TOKEN_2=your_cf_api_token_2 CF_LABEL_2=Cloudflare - Studio

Pages projects are auto-discovered automatically!
